# Starter Sounds

The app ships with a small set of free sounds that appear in the Sample Library
and can be loaded into the Sampler. All of them are released under **CC0 1.0
Universal (public domain)**, so they can be used commercially, changed and
redistributed without attribution.

## Drums

Source: **Stargate Sample Pack** — an open source, public domain sample pack.
https://github.com/stargatedaw/stargate-sample-pack (CC0 1.0)

Files (all from `stargate-sample-pack/microlag/One-Shots/Drums/`):

| File in app | Original |
| --- | --- |
| `starter-kick-1.wav` | `Kick1.wav` |
| `starter-kick-2.wav` | `Kick2.wav` |
| `starter-snare.wav` | `Snare1.wav` |
| `starter-clap.wav` | `Clap1.wav` |
| `starter-hat.wav` | `Hihat1.wav` |
| `starter-hat-2.wav` | `Hihat2.wav` |

## Pitched notes

Source: **VSCO 2 Community Edition** — an open-source orchestral library.
https://github.com/sgossner/VSCO-2-CE (CC0 1.0)

Files (from `Woodwinds/Flute/stac/`, staccato flute, first round robin):

`starter-flute-c4.wav`, `starter-flute-e4.wav`, `starter-flute-a4.wav`,
`starter-flute-c5.wav`, `starter-flute-e5.wav`, `starter-flute-a5.wav`.

The original files were renamed with the `starter-` prefix so the app can find
them inside its bundle and keep them apart from imported audio.
